# 灵感私藏模块设计

## 产品目标

「灵感私藏」承载账号的点赞同步与收藏同步任务，作为独立业务模块与普通的
内容采集任务完全分离，后续在此模块上发展独立业务线。

运营人员在日常浏览抖音时，会用账号点赞或收藏有价值的内容。灵感私藏把
这些私有标记的内容同步进系统，形成可检索、可后处理的私藏作品库。

两类同步任务：

- **点赞同步**（`liked`）：同步指定账号"喜欢"列表中的作品。
- **收藏同步**（`collected`）：同步指定账号"收藏"列表中的作品。

点赞与收藏属于账号私有数据，每个同步任务只能绑定一个已管理账号，
不允许多账号分片，也不允许账号池。

## 模块边界

灵感私藏与普通采集任务的关系：

- 普通任务（关键词搜索、指定作品、创作者作品、视频作者作品）归属赛道，
  在任务页和赛道详情中管理。
- 私藏同步任务**完全脱离赛道**，不选择赛道、不出现在任何赛道视图，
  只在灵感私藏模块中创建和管理。
- 普通任务的创建入口和任务列表不再出现点赞/收藏类型。

模块包含三个功能区：

1. **同步任务**：创建、列表、详情、取消、恢复，展示执行进度与结果计数。
2. **私藏作品库**：同步任务落库的作品，带来源标记（点赞/收藏）、
   所属同步任务和同步时间；支持按来源、任务筛选。
3. **动作记录**：同步过程中生成的匿名化账号动作记录（现有
   `douyin_user_action`），按任务与动作类型查看。

## 数据与存储

实际表结构中，`douyin_aweme`、`douyin_comment`、`douyin_media_asset`、
`douyin_subtitle` 全部挂在 `crawl_task.id` 上，赛道归属经由任务传导。
因此采用**查询层隔离**而非物理分表：

- 新增迁移：`crawl_task.track_id` 改为可空。私藏同步任务
  `track_id = NULL`；复合外键 `(track_id, owner_id)` 对 NULL 自动放行，
  不破坏现有约束。
- 私藏任务的作品仍写入 `douyin_aweme`，评论、媒体、字幕链路零改动，
  下载、翻译、重试等能力直接可用。
- 赛道作品库（含"全部赛道"视图）在查询层排除 `liked`/`collected`
  类型任务的作品；私藏作品只在灵感私藏模块展示。数据不复制、不删除。
- 历史点赞/收藏任务（带有赛道归属）在灵感私藏中可见可管理；其已落库
  作品同样从赛道作品库隐藏，改由灵感私藏展示。历史数据本身不修改。

## 配置与执行

同步任务复用现有任务引擎与字段：

- 来源类型（点赞/收藏）、绑定账号（单选，必填，不允许账号池与多账号）。
- 采集规模：`max_awemes` 为扫描候选上限。
- 评论开关、子评论开关、单作品评论上限。
- 风控节奏（快/稳/超级稳）与请求间隔；账号最小请求间隔仍是下限。
- 媒体处理：是否下载视频、是否翻译字幕、存储后端。
- 登录方式：默认使用已管理账号的持久登录态；支持一次性 Cookie
  （仅内存使用，不落库）。
- 支持取消、中断恢复；恢复沿用原任务断点与幂等约束。
- 内容过滤门槛（发布时间、点赞数、评论数）与现有普通任务保持一致，
  本次只做模块分离，不增删任何采集能力。

## 后端结构

新增应用层模块 `app/application/douyin/vault/` 作为外观层：

- 校验来源类型与单账号约束，强制 `track_id = NULL`，组装
  `CrawlTaskCreate` 后调用现有任务服务创建与执行。
- 列表、详情、取消、恢复、作品库、动作记录均按
  `crawl_type in (liked, collected)` 过滤后委托现有查询服务。

新增路由组 `/douyin/vault/*`：

- `POST /douyin/vault/tasks`：创建同步任务。
- `GET /douyin/vault/tasks`：任务列表（含进度与计数）。
- `GET /douyin/vault/tasks/{id}`：任务详情。
- `POST /douyin/vault/tasks/{id}/cancel`：取消。
- `POST /douyin/vault/tasks/{id}/resume`：恢复。
- `GET /douyin/vault/works`：私藏作品库（按来源/任务/分页筛选）。
- `GET /douyin/vault/actions`：动作记录（按任务/动作类型/分页筛选）。

现有接口调整：

- 普通任务创建接口拒绝 `liked`/`collected` 类型，返回可恢复的业务错误，
  提示使用灵感私藏接口。
- 普通任务列表查询排除这两类任务。
- 任务恢复与媒体处理链路中 `track_id` 为 NULL 时不再写入请求快照
  （修复 `str(task.track_id)` 产生字符串 "None" 的隐患）。

MCP 新增 vault 工具组（创建/列表/详情/取消/恢复/作品/动作），
原任务工具不再返回点赞/收藏任务。

## 前端

- 新路由 `/douyin-vault`，单页三页签：「同步任务」（统计卡片、任务表格、
  创建对话框、进度轮询、取消/恢复操作）、「私藏作品」（复用现有作品卡片
  与媒体操作组件）、「动作记录」。
- 侧边栏新增「灵感私藏」入口。
- 普通任务创建对话框移除"当前账号点赞/当前账号收藏"选项；普通任务列表
  与赛道详情的任务列表不再显示这两类任务。

## 兼容与迁移

- 迁移仅把 `crawl_task.track_id` 改为可空，不修改任何历史行。
- 旧任务、旧作品、旧评论数量不变；唯一可见性变化是点赞/收藏类任务的
  作品从赛道作品库移到灵感私藏展示。
- 服务硬限制与隐私规则保持不变：账号 hash 脱敏、Cookie 不落库、
  原始账号标识不写入断点。

## 验收标准

- 普通任务列表、创建对话框、赛道详情任务列表均不再出现点赞/收藏类型。
- 灵感私藏可创建两类同步任务并正常执行、取消、恢复；作品、评论、
  媒体、字幕链路正常。
- 私藏作品只出现在灵感私藏；赛道作品库任何视图都看不到。
- 普通任务创建接口与 MCP 工具拒绝 liked/collected 并给出引导提示。
- 中断恢复后私藏任务断点、计数与幂等行为与普通任务一致。
- REST、MCP、OpenAPI 客户端、桌面与移动端页面保持一致。
- 单元、迁移、契约、业务与浏览器回归测试全部通过。
