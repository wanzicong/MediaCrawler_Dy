## 0. 文档说明

### 0.1 编写目的

本文档以「逆向产品能力」为目标：不参考任何既有需求文档，纯粹从当前前端源码反向还原这套产品的**交互、设计与模块能力**，输出一份可以让产品/设计/研发三方对齐的"产品说明书"。每个页面均包含：页面用途、区块结构、交互元素、**逐字 UI 文字草稿**（含按钮、占位符、空态、错误态、Toast、校验提示）、业务规则与权限约束。

### 0.2 阅读约定

- 文案均为源码**逐字摘录**，未做润色；`{n}`、`{name}` 等花括号表示运行期变量占位。
- 「状态枚举」中的取值（如 `queued`、`running`）为前后端约定英文值，右侧中文为界面实际展示文案。
- 「轮询」指前端 `react-query` 的自动刷新间隔。
- 「线框」为 ASCII 文字版布局草稿，仅表达区块层级与位置，不表达像素尺寸。

### 0.3 产品一句话概述

**灵感采集台**是一个面向抖音内容运营的内部工作台：以「赛道」组织市场方向，以「关键词/任务」驱动抖音内容采集，沉淀视频、评论、标签三类内容资产，并通过托管账号池完成评论、回复、私信三类人工确认式互动，全程附带浏览器实时监控与风控配额管理。

### 1.3 角色与权限模型

| 角色 | 判定字段 | 能力边界 |
| --- | --- | --- |
| 访客 | 无 `access_token` | 仅可访问 4 个认证页 |
| 登录用户 | `isLoggedIn()`（localStorage 存在 `access_token`） | 全部业务页面；抖音各页**无页面级角色门槛** |
| 超级管理员 | `user.is_superuser = true` | 额外可见/可访问「用户管理」；侧边栏该项仅对超管渲染 |

权限规则细节：

1. **登录守卫**：所有 `_layout` 下页面在路由 `beforeLoad` 中校验登录态，未登录一律重定向 `/login`。
2. **认证页反向守卫**：已登录用户访问登录/注册/找回/重置页一律重定向回 `/`。
3. **重置密码前置**：URL 无 `token` 查询参数时重定向到 `/login`。
4. **资源级越权**：不由前端路由拦截，统一由后端 403/404 表达，前端展示「{资源}不存在，或当前账号无权访问」。
5. **敏感数据可见性**：互动任务完整内容、操作截图「仅任务所有者可见」；账号平台标识不可逆脱敏；临时登录凭据仅内存使用、不落库、不写日志（均为界面文案承诺）。
6. **自我操作限制**：用户管理表格中当前登录管理员行不渲染操作菜单（不能在后台改/删自己）。

### 1.4 全局设计系统

**主题三维度**（`ThemeProvider`，全部持久化到 localStorage，键前缀 `vite-ui-theme`）：

| 维度 | 选项 | 存储/作用方式 |
| --- | --- | --- |
| 明暗模式 | 浅色 / 深色 / 跟随系统（默认：跟随系统） | `<html>` 挂 `light`/`dark` class；跟随系统时监听 `prefers-color-scheme` 变化 |
| 主题风格 | 清透蓝（ocean）/ 专业灰（graphite）/ 跃动紫（violet，默认） | `<html data-preset="...">`，CSS 变量换肤 |
| 信息密度 | 舒适（默认）/ 紧凑 | `<html data-density="...">`，全局间距缩放 |

**指标卡色调体系**（`MetricCard` 的 `tone`）：violet（紫）/ blue（蓝）/ mint（薄荷绿）/ coral（珊瑚橙）/ rose（玫红）/ slate（石板灰），每种色调带顶部渐变光晕与图标底色，悬停上浮。

**组件语言**：

- 圆角卡片（`rounded-2xl`）+ 细边框 + 浅阴影为全局容器语言；
- 页面骨架统一为「PageHero（页头）→ MetricCard 指标行 → FilterPanel 筛选区 → 数据表格/卡片网格 → 分页」；
- 图标库 lucide-react；
- 移动端断点 `md`（表格↔卡片切换）、网格断点 `sm/xl/2xl`；
- 全站支持 `motion-reduce`（减少动效偏好）与无障碍跳转链接「跳到主要内容」。

### 2.7 全局交互规则

1. **登录守卫**：无 token 访问任何业务页 → `/login`；token 失效由接口 401 触发登出。
2. **确认对话框**：破坏性操作（删除、批量迁移、批量重试等）一律 `window.confirm` 或确认 Dialog 二次确认，文案逐字见各章节。
3. **自动刷新**：进行中数据全部轮询（1s~15s 不等，完整汇总见第 9.8 节）；手动「刷新」按钮普遍存在于页头。
4. **乐观反馈**：所有写操作以 Toast「操作成功/操作失败」收尾；行级操作以 `mutation.variables` 精确禁用当前行按钮。
5. **筛选即重置页码**：所有列表页筛选变更自动回第 1 页。

## 3. 认证模块

4 个认证页共用 `AuthLayout` 外壳：左侧品牌栏（仅大屏显示）+ 右侧表单卡 + 右上角明暗切换。

品牌栏逐字文案：

- eyebrow：「年轻、高效的内容运营空间」
- 大标题：「把采集、管理与内容洞察，放进一个清爽的工作台。」
- 特性点：「任务状态实时更新」「账号与隐私安全隔离」
- 底部：「抖音内容运营工作室」

共同规则：已登录用户访问任一认证页 → 重定向 `/`；密码全站最少 8 位；表单校验 `onBlur` 触发、展示全部错误。

### 3.1 登录页 `/login`

**用途**：邮箱 + 密码登录。

**区块**：标题区 → 表单（邮箱、密码）→ 提交按钮 → 注册引导。

**UI 文字草稿**：

| 元素 | 文案 |
| --- | --- |
| H1 | 欢迎回来 |
| 副标题 | 登录后继续管理你的采集任务与内容资产 |
| 字段标签 | 邮箱（占位 `user@example.com`） |
| 字段标签 | 密码（占位「请输入密码」；右上链接「忘记密码？」→ `/recover-password`） |
| 提交按钮 | 登录 |
| 底部引导 | 还没有账号？ 立即注册（→ `/signup`） |
| 校验 | 请输入有效的邮箱地址 / 请输入密码 / 密码至少需要 8 个字符 |

**后果**：成功后写 token 跳转首页；后端错误经中文化映射弹 Toast（如「邮箱或密码错误」「账号已停用」）。

### 3.2 注册页 `/signup`

**用途**：新用户注册。

## 9. 领域状态机与业务规则汇总

### 9.1 采集任务状态机（CrawlTaskStatus）

| 状态值 | 界面文案 | 说明 |
| --- | --- | --- |
| queued | 排队中 | 活跃 |
| waiting_login | 等待扫码 | 活跃；触发二维码卡片（列表页该状态计入「需处理」） |
| running | 运行中 | 活跃 |
| processing_media | 处理视频/字幕 | 活跃 |
| cancelling | 取消中 | 活跃 |
| succeeded | 已完成 | 终态 |
| failed | 失败 | 终态；计入「需处理」 |
| cancelled | 已取消 | 终态 |
| interrupted | 已中断 | 终态；计入「需处理」 |

- 活跃集合 = queued / waiting_login / running / processing_media / cancelling → 详情页可「取消任务」，不可「继续任务」。
- 终态可「继续任务」（需 can_resume_crawl 或 can_resume_media），不可取消。
- 断点续跑分「继续爬取」与「继续视频下载和字幕」两个独立范围；记录 resume_count、last_resumed_at、checkpoint_phase（crawl/media）。

### 9.2 关键词状态（DouyinKeywordStatus）

| 状态值 | 界面文案（关键词页/赛道详情页） |
| --- | --- |
| unprocessed | 未爬取 |
| active | 进行中 |
| crawled | 已爬取 |

### 9.3 媒体下载 / 字幕 / 迁移状态机

| 域 | 状态流转 | 界面文案 |
| --- | --- | --- |
| 下载（asset.status） | queued → downloading → downloaded / failed | 等待中 / 下载中 / 已下载 / 失败 |
| 字幕（subtitle.status） | pending → running → completed / failed | 等待字幕 / 字幕处理中 / 字幕完成 / 失败；无字幕「未启用」/「未生成字幕」/「无字幕」 |
| 迁移（migration_status） | idle / queued / uploading / verifying / switching / cleanup_pending / completed / failed | 无需迁移 · 未迁移 / 等待上传 / 上传中 / 完整性校验中 / 切换存储中 / 云端存储已生效，等待清理本地文件 / 迁移完成 / 迁移失败 |

- 迁移安全承诺（界面明示）：**只有完整回读校验通过后才删除本地文件**，任何一步失败本地文件保留。
- 处理中集合 {queued, uploading, verifying, switching, cleanup_pending} 触发 2 秒轮询。
- 重试 retryMedia 同时重试下载 + 字幕；retranslateMedia 单独重提字幕。
- 字幕技术：远程 Whisper API，失败不回退本地模型；以 VTT data URI 注入播放器 `<track>`。

### 9.4 互动任务状态机（DouyinInteractionStatus）

| 状态值 | 界面文案 | 徽标配色 |
| --- | --- | --- |
| pending_confirmation | 待确认 | outline |
| queued | 排队中 | outline |
| running | 发送中 | outline |
| succeeded | 已成功 | default |
| failed | 失败 | destructive |
| blocked | 已暂停 | destructive |
| needs_review | 待人工核对 | outline |
| cancelled | 已取消 | outline |

- 主流程：pending_confirmation →（人工确认）→ queued → running → succeeded / failed / blocked / needs_review / cancelled。
- 两段式人工确认：发送前检查 → 草稿 → 确认发送；重复目标+内容 24 小时内拦截；内容加密、不写日志；作者标识仅执行时临时解析。
